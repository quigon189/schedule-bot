# Schedule Bot System

Многосервисная система для управления учебными расписаниями с интеграцией Telegram, VK и AI-ассистентов. Система предоставляет полный цикл управления расписаниями: от парсинга изменений из социальных сетей до отправки уведомлений пользователям через AI-ассистентов.

## 🎯 Основные возможности

- **Управление пользователями** - регистрация через коды, ролевая модель (студенты, преподаватели, администраторы)
- **Расписания групп** - хранение и предоставление расписаний по учебным периодам
- **Изменения расписаний** - парсинг из VK, ручное добавление, уведомления
- **Telegram бот** - основной интерфейс для пользователей
- **AI интеграция** - MCP сервер для взаимодействия с AI-ассистентами
- **Автоматизация** - автоматический парсинг изменений из VK

### Технологический стек

- **Backend**: Go (чистая архитектура), Python (aiogram)
- **База данных**: PostgreSQL
- **Контейнеризация**: Docker, Docker Compose
- **API**: REST, MCP (Model Context Protocol)
- **Документация**: Swagger/OpenAPI
- **OCR**: Tesseract
- **Интеграции**: VK API, Telegram Bot API

## 📦 Быстрый старт

### Предварительные требования

- Docker 20.10+
- Docker Compose 2.0+
- Go 1.25+ (для разработки)
- Python 3.11+ (для разработки)

### Запуск через Docker Compose

1. **Клонирование репозитория:**
```bash
git clone https://github.com/quigon189/schedule-bot.git
cd schedule-bot
```

2. **Настройка переменных окружения:**
```bash
cp .env.example .env
# Отредактируйте .env файл, указав необходимые настройки
```

3. **Запуск всех сервисов:**
```bash
docker-compose up -d
```

4. **Проверка состояния:**
```bash
docker-compose ps
```

5. **Настройка n8n:**
Необходимо авторизоваться в локальном n8n и импортировать workflow из каталога data

## 📖 Использование

### Регистрация пользователей

1. **Создание кода регистрации:**
   - Администратор используя телеграм бот вызывает команду /code и проходит диалог

2. **Регистрация в Telegram боте:**
   - Откройте Telegram бота
   - Отправьте полученный код
   - Бот автоматически привяжет вас к группе

### Получение расписания

**Через Telegram бота:**
- Используйте команду `/schedule`
- Выберите группу и учебный период

### Получение изменений

**Через Telegram бота:**
- Команда `/changes`
- Автоматические уведомления при появлении новых изменений

### Использование AI-агента

**Доступные инструменты:**
- `send_changes_to_user` - отправить изменения пользователю

**Взаимодействие через Telegram бота:**
- Отправить в бота сообщение с указанием требуемых параметров на естественном языке. Например: Есть изменения в расписании на завтра?
- Telegram бот перенаправляет подобные сообщения в n8n AI-агента
- AI-агент используя LLM (локально или облочно, взависимости от выбраного workflowол) обработает запрос и сформирует ответ в виде текста
- Так же AI-агент попытается воспользоваться доступными инструментами на MCP-сервере, если это будет необходимо
