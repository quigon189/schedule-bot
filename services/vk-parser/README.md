# VK Parser Service

Сервис для автоматического парсинга изменений в расписании из группы ВКонтакте. Автоматически извлекает информацию о изменениях из постов, распознает текст с изображений и отправляет данные в Schedule Service.

## Функционал

### Парсинг ВКонтакте
- Получение постов со стены группы ВК
- Фильтрация постов по заданному паттерну
- Скачивание изображений из постов
- Поддержка пагинации (ограничение количества обрабатываемых постов)

### OCR распознавание
- Распознавание текста с изображений с помощью Tesseract
- Поддержка русского и английского языков
- Автоматическое извлечение дат из распознанного текста

### Интеграция
- Автоматическая отправка данных в Schedule Service
- Отслеживание уже обработанных постов
- Периодическая проверка новых постов

## Конфигурация

### Переменные окружения

| Переменная | Описание | Значение по умолчанию |
|------------|----------|----------------------|
| `VK_ACCESS_TOKEN` | Токен доступа VK API | (обязательно) |
| `VK_GROUP_ID` | ID группы ВК (без знака минус) | `1` |
| `CHECK_INTERVAL_MINUTES` | Интервал проверки новых постов (в минутах) | `5` |
| `PATTERN` | Паттерн для поиска в тексте | `"Изменение в расписании на"` |
| `SCHEDULE_SERVICE_URL` | URL Schedule Service | `http://schedule-service:8080` |
| `MAX_POSTS` | Максимальное количество постов для обработки за раз | `20` |
| `TESSERACT_PATH` | Путь к исполняемому файлу Tesseract | `/usr/bin/tesseract` |

### Пример .env файла
```env
VK_ACCESS_TOKEN=ваш_токен_vk_api
VK_GROUP_ID=123456789
CHECK_INTERVAL_MINUTES=10
PATTERN=Изменение в расписании на
SCHEDULE_SERVICE_URL=http://schedule-service:8080
MAX_POSTS=30
TESSERACT_PATH=/usr/bin/tesseract
```

## Запуск

### Требования
- Go 1.25+
- Tesseract OCR 5.0+ с поддержкой русского языка
- Docker (опционально)
- Доступ к API ВКонтакте

### Docker
```bash
docker build -t vk-parser .
docker run -p 8080:8080 --env-file .env vk-parser
```

### Docker Compose
```yaml
# В составе общего проекта
docker-compose up vk-parser
```

## Принцип работы

### Алгоритм работы парсера:
1. **Периодическая проверка:** Сервис запускает проверку каждые N минут (настраивается через `CHECK_INTERVAL_MINUTES`)
2. **Получение постов:** Получает последние посты со стены указанной группы ВК
3. **Фильтрация:** Пропускает уже обработанные посты
4. **Обработка изображений:** Для каждого поста скачивает все изображения
5. **OCR распознавание:** Распознает текст с каждого изображения
6. **Поиск даты:** Ищет в тексте дату по паттерну "Изменения в расписании на ДД.ММ.ГГГГ"
7. **Отправка данных:** Если дата найдена, отправляет данные в Schedule Service

### Формат отправляемых данных:
```json
{
  "date": "2025-09-01",
  "description": "Текст поста ВК",
  "image_urls": ["https://example.com/photo1.jpg", "https://example.com/photo2.jpg"]
}
```

## Настройка паттерна поиска

### Текущий паттерн:
```regex
Изменения в расписании на (\d{2})\.(\d{2})\.(\d{4})
```

### Формат даты:
- ДД.ММ.ГГГГ (например: 01.09.2025)
- Преобразуется в формат ГГГГ-ММ-ДД для Schedule Service

### Изменение паттерна:
Для изменения паттерна поиска измените переменную окружения `PATTERN` или измените регулярное выражение в функции `checkPattern` в файле `internal/parser/parser.go`.
